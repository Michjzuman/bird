Bird will be a tui based code editor that will let you fly over your codebase.

[ NOTE: THIS PROJECT IS STILL IN EARLY DEVELOPMENT ]

---

Build requirements:
```bash
llvm clang ncurses git make
```
Download and compile:
```bash
git clone https://github.com/michjzuman/bird
cd bird
make
```
Linux:
```bash
cp bird /usr/bin
```
macOS:
```bash
cp bird /usr/local/bin
```
